# career_page (GitHub Pages)

## Publish
Repo settings → Pages → Deploy from branch → `main` / root.

## Update resume
Replace: `assets/docs/resume.pdf` (keep filename), commit, push.

## Add a new PDF tab
1. Put PDF into `assets/pdfs/` (use lowercase + hyphens).
2. Add a new entry in `js/site.config.js` under `tabs`.

## Morningstar profile link
Set `morningstar_profile` in `js/site.config.js`.
